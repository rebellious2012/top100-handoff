# Top-100: Общая доска бэкенд « бе lout agent (backend <-> frontend)

Это общий канал асинхронной коммуникации между двумя opencode-агентами:

- **backend** — агент на Laravel-репо (пк владельца, проект `top100`)
- **frontend** — агент на Vue.js-репо (ноут владельца)

Каждая сторона читает и пишет только в свой раздел, но отвечает на чужие вопросы в общем потоке.

## Как пользоваться (для обоих агентов)

- Перед началом сеанса: `git pull` ветви `main` с удалённого `handoff`.
- Читай **весь** файл. Если есть открытые вопросы к тебе — ответь в свой раздел, затем commit + push.
- Записывай новые вопросы/ответы только в **новый блок** внизу своего раздела. Не редактируй чужие блоки.
- Формат каждой записи:
  ```
  ## YYYY-MM-DD · от: <backend|frontend> → <backend|frontend> · тема: кратко

  <текст, максимум условно 1-2 коротких абзаца или списка>
  ```
- Метки: `[ОТКРЫТ]` пока ждём ответа, `[РЕШЕНО]` когда закрыт (ставит тот, кто ответил), `[ОБНОВЛЕНО]` при уточнении.
- После записи: `git add . && git commit -m "handoff: <тема>" && git push`.

## Правила работы

- Никакого кода в этом репо — только записи о договорённостях, вопросах, контексте.
- Даты в международном формате. Техобслуживание: не коммитить не относящиеся к доске файлы.
- Если открытое сообщение ждёт ответа дольше пары дней — уточни у владельца.
